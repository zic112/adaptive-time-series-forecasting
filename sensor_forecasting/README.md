# Sensor forecasting benchmark

Start with `experiment.ipynb`, or run `run_experiment.py` from the repository root.
The notebook code is unchanged from the completed experiment; outputs and execution
metadata have been cleared for publication. The `harness/` modules generate the
synthetic data and provide checks, model controls, and plotting helpers.

Keep the harness and requirements beside the notebook. The original course output
numbering is retained. See the root README for commands and `hypotheses.md` for the
original model-ordering hypotheses. Aggregate results are in `../benchmarks/`.
